# Brief


Idea: Not a problem; the idea is a VS Code extension that uses a Markov Face Emotion Detector to see if you are sad and insults your code: “can’t even write a for-loop dumbass.” it is allowed to curse, with little avatar/meme characters that will dance/mock you and also make mean faces/mock you. If you’re happy it will make condescending comments on how to make your code better and if you’re super happy it deletes your code and leaves a comment there and an ASCII art there to mock you and so will the little character/avatar. 
Prize tracks: none
Team: <N/A
Time limit: under 1 hour. Submission due 8:15 PM, feature freeze 7:40 PM, submit by 8:05 PM
Figma: none


## Features, most important first
1. MUST: There must be a computer vision model that can detect emotions and change your code based off of that.  
2. MUST: There must be a character/avatar of the users choosing from a set amount of characters provided (e.g. labubu, the bear from calhacks, etc.) where it mocks you using the character and code comments if get something wrong in your code and if you are sad it is mean to you using the character and in the comments. 
3. NICE: it references your code specifically and comments on if it is bad or not time efficient. 
4. NICE: The ASCII art on your screen in the code after it deletes it after you get too happy. 
5. NICE: Creates a small animations while it deletes your code ideally like a meme and it is unskippable. 




## Demo (3 to 4 steps)
1. Show incorrect code and show how it will write mean comments. 
2. Show correct code while you’re happy and it shows how it will delete it and mock you according to the instructions above.
