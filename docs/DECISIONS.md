| 2026-10-16 | [fastapi-developer] Roast backend choices: startup warm-up is awaited in the lifespan (up to 120 s, so uvicorn accepts connections only after the model is resident; a failed warm-up logs a warning and the app still starts with `ai_ready=False`). All prompt wording lives in `apps/api/app/prompts/roast.py`; `error_body` moved to `apps/api/app/errors.py`; `anthropic`/`supabase` clients removed from the lifespan. | Keeps the first demo request fast and the content rule enforced on untrusted output without touching the contract. |
